# Recipes

Complete, copy-paste patterns adapted from a production app. Each one is a runnable file, tested with the library.

| Recipe | What it builds |
| --- | --- |
| [Sessions and API tokens](sessions-and-tokens.md) | a web app and its API on the same routes |
| [Personal access tokens](personal-access-tokens.md) | users create, list and revoke their own tokens |
| [Role-gated routes](role-gated-routes.md) | admin-only endpoints from one validator |
| [Sign out everywhere](sign-out-everywhere.md) | a device list with per-session revocation |
| [Two-factor login](two-factor.md) | TOTP codes, a pending-login cookie and recovery codes |
| [Sign in with OpenID Connect](oidc-sign-in.md) | "Log in with Google / Keycloak / Entra" |
| [WebSocket tickets](websocket-tickets.md) | authenticating browser WebSockets without cookies |
| [Audit your routes](audit-routes.md) | a CI test that fails on unguarded routes |
